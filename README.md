# ЛР №4 — класифікація ірисів (KNN)


## Запуск

```bash
python3 main.py
```

Або відкрийте `iris_classification.ipynb` у VS Code / Jupyter та виконайте всі комірки.

## Алгоритм

1. Читаємо дані CSV.
2. Перемішуємо індекси фіксованим seed=0, відділяємо 25 % для тестування.
3. `fit()` зберігає навчальні приклади.
4. `predict_one()` обчислює евклідові відстані та обирає клас найближчого сусіда (k=1).
5. Розраховуємо accuracy і матрицю помилок.
